Microsoft Teams SDK now enables developers to build intelligent agents that participate in conversations across chats, channels, and meetings. New capabilities include targeted messaging, agent sessions, and support for private and shared channels for collaborative workflows. The Teams SDK is generally available in Python, JavaScript, and C#.
